Starting a new cozy game

Bring the kit to a game

Steps

  1. Add "@arcade/cozy-kit": "1.0.0" to the game's package.json, then npm install at the repo root.
  2. Load the fonts, tokens and parts CSS before the game's own CSS.
  3. Call applyLooks(theme, style) on load and after every change.
  4. Save style as a free setting, Soft by default.
  5. Sell THEMES in the shop. FREE_THEMES are always free; set the rest at the game's own prices.
  6. Draw the board with kit tokens only. In Bold, outline with --outline and shadow with --shade, never --ink.

The code

import '@arcade/cozy-kit/fonts.css';
import '@arcade/cozy-kit/kit.css';
import '@arcade/cozy-kit/components.css';
import { applyLooks, FREE_THEMES, THEMES }
  from '@arcade/cozy-kit/themes.js';

applyLooks(save.theme, save.style);

const price = (id) =>
  FREE_THEMES.includes(id) ? 0 : THEME_PRICE[id];
