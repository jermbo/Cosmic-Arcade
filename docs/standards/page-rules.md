# Page rules

Each rule that this page does not name stays as the baseline tells it.

## Pages in the voice of the owner

Changes: `language`, `page-length`.

The vision page speaks in the voice of the owner: first person, plain and human. It does not use Simplified Technical English. It can run a little longer than the baseline length when the voice needs the room.

Every other page keeps the baseline language.
