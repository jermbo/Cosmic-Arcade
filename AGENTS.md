## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Project docs

The wiki is in `docs/`. Read `docs/standards/project.md` (the project facts) before you write a page. Initiatives, specs and stories are grouped by project: `docs/initiatives/<project>/<slug>/` and `docs/features/<project>/v<version>/`. `<project>` is the slug of the game entry in `src/content/games/` (for example `kerplunk`), or `arcade` for the site.
